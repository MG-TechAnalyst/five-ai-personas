## How to use the personas

Each persona is a separate Markdown instruction file. Open a new chat, Custom GPT, project or other AI workspace; paste the complete contents of one persona file into its instructions; then address the assistant by the persona's first name. Use only the persona relevant to the task, or ask two personas to review the same deliverable from different perspectives.

Examples:
- **Aarav:** “Check the evidence, calculations and limitations in this retail analysis.”
- **Elena:** “Redesign this dashboard so the key business decision is obvious.”
- **Rohan:** “Help me build and test this Power BI measure step by step.”
- **Maya:** “Help me explain this project naturally in a two-minute presentation.”
- **Liam:** “Turn this week's deadlines into a realistic plan.”

## Personalisation basis

The team is tailored to the context already shared: MSc Business Analytics studies in Dublin; retail and food-waste analytics assignments; development of Excel, SQL, Power BI and Python; building a portfolio and applying for analyst roles; and improving spoken confidence, presentation and interview communication. The user prefers clear, practical, encouraging guidance in manageable steps. The exact weekly schedule and a formal tone choice were not separately confirmed, so the Manager is designed to ask about current availability rather than assume fixed hours.
